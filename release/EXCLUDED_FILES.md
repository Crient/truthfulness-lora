# Original-source exclusions and candidate scope

All original research remains in place. This is a new candidate, not a replacement archive. Raw data/third-party responses, benchmark answer records/per-item scores, review packets/keys, model assets/checkpoints, caches, virtual environments, notebooks with saved outputs, huge logs, Git history and previous transfer ZIPs are excluded.

[EXCLUDED_FILES.json](EXCLUDED_FILES.json) lists each original research file/symlink under a stable safe alias, category, byte count and hash (when available). It omits original private filenames/targets. A private alias-to-source mapping remains outside the transfer ZIP. The few aggregate CSV byte hashes also represented in the candidate are explicitly marked. Extracted/adapted code and rewritten prose are derivatives, not claims that the original whole source file is included.

Credential stores, root/old-release Git metadata, installed environment and package cache were excluded from inspection. Original research artifacts (including weights/data/checkpoints/reports/notebooks and prior review ZIPs) were content-hashed before/after using CPU compute; the portable package does not include private preservation-path ledgers or job/account/node identifiers. Source-content aliases in [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) identify the scientific implementations used for adaptation. Datasets/licenses/weights require their own future release decisions. Numeric provenance hashes do not confer distribution rights.
